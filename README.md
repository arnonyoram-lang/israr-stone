# אתר ישראר סטון מארבל

אתר תדמית וקטלוג בעברית לספק האבן והשיש **ישראר סטון מארבל בע״מ**, עם פרטי הקשר של יורם (מייל וטלפון 050-8224522).
התוכן והתמונות נלקחו מאתר הספק (israrstone.com) ומקטלוג החיפויים שלו (PDF, 23 עמודים).

## מה יש באתר
- **פתיח** עם מצגת תמונות וסלוגן הקטלוג "יופי קבוע וקסום".
- **אודות** — החברה המשפחתית, מחצבות, מפעל, יבוא ואספקה.
- **קטלוג חיפויים** — 22 מוצרים עם סינון לפי סוג, ולכל מוצר גלריית תמונות מלאה.
- **מפרט** — גימורים, עוביים (2.2 / 3 ס״מ), צורות אספקה ושימושים (מתוך הקטלוג).
- **גרניט בינלאומי** — 11 גוונים.
- **תהליך עבודה**, **פרויקטים** (גלריה), **שירותים**, **שאלות נפוצות**.
- **בקשת הצעת מחיר** — הגולש מסמן מוצרים בקטלוג, והם נכנסים לטופס. השליחה פותחת מייל מוכן או הודעת וואטסאפ מוכנה.

## איפה הכול
| קובץ / תיקייה | מה יש שם |
|---|---|
| `index.html` | מבנה האתר וכל הטקסטים הקבועים |
| `js/content.js` | **פרטי הקשר**, רשימת המוצרים, הגרניט והפרויקטים — כאן עורכים |
| `js/main.js` | ההתנהגות (גלריה, סינון, טופס, רשימת הצעת מחיר) |
| `css/style.css` | העיצוב |
| `DESIGN.md` | כללי העיצוב (צבעים, גופנים, רכיבים) |
| `images/` | כל התמונות, מותאמות לאינטרנט (WebP) |

## איך משנים טלפון
פותחים את `js/content.js` ומשנים את המספר בשורה `phone: "050-8224522"`.
כפתורי החיוג, הוואטסאפ הצף ו"שליחה בוואטסאפ" מתעדכנים לבד. השארת השדה ריק מסתירה אותם.

## איך מריצים אצלי במחשב
```bash
python -m http.server 5180
```
ואז לפתוח בדפדפן: `http://localhost:5180`
